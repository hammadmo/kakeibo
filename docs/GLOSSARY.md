# Glossary

One name for each thing. Used in buttons, menus, titles, tooltips, errors, and VoiceOver.

| Term | Means | Not |
| --- | --- | --- |
| Limit | A plan cap Anthropic resets on a schedule | quota, cap, allowance |
| Session limit | The 5-hour limit | 5h window, block, rolling limit |
| Weekly limit | The 7-day limit across all models | week quota |
| Fable limit | The 7-day limit for Fable models only | Fable quota |
| Used | Share of a limit already spent, in percent | utilization, consumed |
| Resets | When a limit goes back to 0% ("Resets in 2 h 14 m") | renews, refills |
| Tokens | Input + output + cache tokens from Claude Code | usage, credits |
| Cost | Estimated API-price value of the tokens, in USD; not a bill | spend, price, charge |
| Surface | Where Claude was used: Claude Code, Chats, Cowork, Other (Anthropic's names) | app, product, channel |
| Project | A folder Claude Code worked in | repo, workspace |
| Today | Since local midnight | last 24 h |
| Gauge | The ensō ring that shows one limit | meter, dial, progress |
| Seal | The vermilion 家 mark; it turns on at 90% Used | badge |
| Refresh | Fetch limits and re-read logs now | reload, sync |
| Dashboard | The full window with charts and projects | main window, stats |
| Summary | Two lines from Claude about a project's day | recap, digest, report |
| Summarize | Ask Claude for a Summary | generate, analyze |
| Summarize Again | Replace today's Summary with a new one | regenerate, refresh |
| Alert | A macOS notification Kakeibo sends | warning, push |
